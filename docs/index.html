这个站点就是 GitHub Pages 的发布根（仓库里的 docs/）。 合约只存一个 URL 字符串，真正的文件名与图片都在这里。这一页把 events/event-<id>.json 逐个读出来，等于按 NFT 阅读器的方式验证了一遍 tokenURI 到底能不能打开。

合约 —

tokenURI 的拼法 tokenURI(id) = baseURI + id + ".json"

所以 baseURI 以 # 结尾时，# 之后的内容浏览器不会发给服务器， 整场活动的每张票都读到同一个静态 JSON。
